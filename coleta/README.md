# Coleta do estudo de concorrentes

Scripts usados para produzir `../estudo-concorrentes.md`. Somente leitura de páginas públicas.

- `coletar.py`: Scrapling com `robots_txt_obey` ligado e pedido HTTP simples. Salva só o texto visível, fora do repositório.
- `inspecionar.py`: sessão MCP do Craft Anything em Clean room. Só abre a página, tira captura de tela e fecha.

Os textos e as capturas dos concorrentes não são versionados.
